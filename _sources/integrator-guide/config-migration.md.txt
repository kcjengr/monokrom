# Config Migration

The `monokrom_plasma setup` subcommand converts a working qtplasmac configuration (generated by StepConf/PnCconf)
into a MonoKrom-compatible configuration. The hardware layer (HAL, INI axis/joint settings) is preserved; only
the VCP-specific layer is transformed.

## Prerequisites

- A working qtplasmac configuration (from StepConf/PnCconf)
- MonoKrom Plasma installed (`pip install -e .`)
- PySide6 and the forked qtpyvcp (`plasma_db` branch) installed

## Quick Start

```bash
# Non-interactive: accept all defaults
monokrom_plasma setup --from-config ~/linuxcnc/configs/my_qtplasmac_config

# Interactive wizard (6 steps)
monokrom_plasma setup --wizard --from-config ~/linuxcnc/configs/my_qtplasmac_config

# Custom output directory
monokrom_plasma setup --from-config ~/linuxcnc/configs/my_qtplasmac_config \
                      --output-dir ~/linuxcnc/configs/my_monokrom_config
```

## Output Location

By default, the output is placed in a sibling directory named `monokrom_<source-name>`:

```
~/linuxcnc/configs/
├── my_qtplasmac_config/          ← source (qtplasmac)
└── monokrom_my_qtplasmac_config/ ← output (MonoKrom)
```

If the source directory name already starts with `monokrom_`, the output goes into the same directory.

## Wizard Flow

The interactive wizard (`--wizard`) guides you through 6 steps:

### Step 1: Select qtplasmac config directory

Scans `~/linuxcnc/configs/` for INI files containing "qtplasmac" or "qt" in the display setting.
Lists found configs for selection. You can also provide the path directly with `--from-config`.

### Step 2: Review detected hardware

Displays:
- Machine name (from `[EMC] MACHINE`)
- Axes and joint count (from `[TRAJ] COORDINATES` and `[KINS] JOINTS`)
- Controller type (detected from HAL files: HM2 7i76E, Parport, etc.)
- Pressure units (from `[PLASMAC] PRESSURE`)

### Step 3: Review settings migration

Shows a table of settings that differ from MonoKrom defaults, with options to:
- **Skip** settings you don't want to migrate
- **Force-update** settings that match defaults but you want to change

Settings are categorized as:
| Category | Meaning |
|----------|---------|
| `UPDATED` | Setting differs from MonoKrom default — will be written to `config.yml` |
| `SKIPPED` | Setting matches MonoKrom default — no change needed |
| `NOT_FOUND_IN_PREFS` | MonoKrom-only setting (uses default) |
| `NOT_FOUND_IN_CONFIG` | qtplasmac-only setting (no MonoKrom equivalent) |

### Step 4: Configure VCP options

Configure:
- `confirm_exit` — Require confirmation on exit (yes/no)
- `fullscreen` — Start in fullscreen mode (yes/no)
- File locations — NC files path and other directories
- User buttons — Import from `.prefs` or configure fresh

### Step 5: Review generated files

Shows a summary of:
- INI transformations (what changed)
- New files to be created
- Files copied as-is

### Step 6: Confirm and generate

Writes all files and generates `setup.log` in the output directory.

## What Gets Generated

### INI File (`monokrom.ini`)

Transformed from the source INI:
- `DISPLAY = monokrom_plasma` (replaces `qtvcp qtplasmac`)
- `CONFIG_FILE = custom_config.yml`
- `FILTER`: `qtplasmac_gcode` → `plasma_gcode_preprocessor`
- `EMCIO`: `TOOL_TABLE` → `DB_PROGRAM = /usr/bin/plasma_tooldbpipe`
- `[PYTHON]` section added (if `python/` directory exists)
- `[HAL]`: Source HAL file renamed to `monokrom.hal`, `TWOPASS = ON` added
- `[HALUI]`: 17 `MDI_COMMAND=(debug,macroN)` entries for pendant macros
- `[DISPLAY]`: MonoKrom options added (`JET`, `CONFIRM_EXIT`, `FULLSCREEN`, `KEYBOARD_JOG`, `HIDE_MENU_BAR`, `GCODE_SYNTAX`)
- `[QTPLASMAC]` section removed
- `[PLASMAC]` section added with `DEBOUNCE`, `PRESSURE`, `MACHINE`, `DEFAULT_CUTCHART`, `SLAT_TOP`
- `[VTK]` section added with `SPINDLE` model path
- `SUBROUTINE_PATH` updated to include `./user_buttons`

### HAL Files

| File | Source |
|------|--------|
| `monokrom.hal` | Renamed from source HAL (e.g., `my_config.hal` → `monokrom.hal`) |
| `qtplasmac_comp.hal` | Copied as-is |
| `custom.hal` | Copied as-is |
| `postgui.hal` | Generated from template (60+ VCP→plasmac nets) |
| `custom_postgui.hal` | Generated — sources `postgui.hal` |
| `shutdown.hal` | Copied as-is |
| `ohmic.hal` | Copied as-is (if present in source) |
| `xhc-whb04b-6.hal` | Copied as-is (if present in source) |

### VCP Configuration

**`custom_config.yml`** — Generated with wizard options:
```yaml
# MonoKrom Plasma VCP config — auto-generated
windows:
  mainwindow:
    kwargs:
      confirm_exit: true
      fullscreen: true

data_plugins:
  file_locations:
    provider: qtpyvcp.plugins.file_locations:FileLocations
    kwargs:
      default_location: NC Files
      local_locations:
        Home: ~/
        Desktop: ~/Desktop
        NC Files: ~/linuxcnc/nc_files
```

**`gcode_syntax.yml`** — Copied from templates (syntax highlighting rules)

**`plasma_table.db`** — Pre-seeded SQLite database from templates

### User Buttons

Generated from `.prefs` `[BUTTONS]` section as NGC subroutines in `user_buttons/`:
```
user_buttons/
├── probe-test.ngc
├── ohmic-test.ngc
├── single-cut.ngc
├── cut-type.ngc
└── ...
```

### Other Files

| File | Action |
|------|--------|
| `tool.tbl` | Copied as-is |
| `M159`, `M190` | Copied as-is (if present) |
| `python/` | Copied as-is (if present) |
| `linuxcnc.var` | Not copied (generated at runtime by LinuxCNC) |
| `material.cfg` | Not copied (not used by MonoKrom) |

## Settings Migration Details

The setup tool reads plasma settings from the source `.prefs` file and writes them to the
output `config.yml` **only when they differ from MonoKrom defaults**.

### Mapped Settings

|------------|-------------------|------|
| `Arc Voltage Offset` | `arc_voltage_offset` | float |
| `Arc Voltage Scale` | `arc_voltage_scale` | float |
| `THC Threshold` | `thc_threshold` | float |
| `THC Delay` | `thc_delay` | float |
| `PID P Gain` | `thc_pid_p_gain` | float |
| `PID I Gain` | `thc_pid_i_gain` | float |
| `PID D Gain` | `thc_pid_d_gain` | float |

| `Float Switch Travel` | `probe_float_travel` | float |
| `Probe Feed Rate` | `probe_speed` | float |
| `Probe Start Height` | `probe_height` | float |
| `Ohmic Probe Offset` | `probe_offset` | float |
| `Ohmic Maximum Attempts` | `probe_ohmic_retries` | int |

| `Void Sense Slope` | `thc_void_override` | float |

### MonoKrom-Only Settings

These have no `.prefs` equivalent and use defaults (logged as `NOT_FOUND_IN_PREFS`):
- `thc_enabled`, `plasma_vad`, `plasma_void_sense`, `plasma_mesh_sense`
- `ohmic_sensing_enabled`, `plasma_auto_volts`, `torch_enable`
- `laser_offset_x/y`, `camera_offset_x/y`, `scribe_offset_x/y`, `ohmic_offset_x/y`
- `plasma_hole_thickness_ratio`, `plasma_max_hole_size`, `plasma_hole_detect_enable`
- `plasma_arc1/2/3_percent`, `plasma_arc1/2/3_distance`, `plasma_leadin_percent/radius`
- `plasma_overburn_percent/adjustment`, `plasma_small_hole_*`, `plasma_use_hidef`
- `framing_feed_rate`, `consumable_offset_x/y`, `probe_test_time`
- `run_save_confirm`, `run_delete_confirm`

### qtplasmac-Only Settings

These have no MonoKrom equivalent (logged as `NOT_FOUND_IN_CONFIG`):
- `THC Sample Counts`, `THC Sample Threshold`
- `DRO position`, `Flash error`, `Hide run`, `Hide pause`, `Hide abort`
- Button names/codes beyond what MonoKrom uses
- `Port` (Powermax serial)
- `keyboard shortcuts`, `soft keyboard`, `show materials`
- `Cut Height Delay`, `Gouge Speed`, `Gouge Distance`, `Creep Speed`, `Creep Distance`
- `Pierce Type`, `Pierce Motion Delay`, `Pierce End Height`
- All `[STATISTICS]` values, `[COLOR_OPTIONS]`, `[CAMERA_OFFSET]`, `[POWERMAX]`

## Setup Log

A `setup.log` file is written to the output directory documenting:
- Source and output config paths
- Date/time of generation
- Settings migration details (UPDATED, SKIPPED, NOT_FOUND_IN_PREFS, NOT_FOUND_IN_CONFIG)
- INI transformations (section changes)
- Files copied, generated, and derived

## Post-Migration

After running the setup:

1. **Review the generated `monokrom.ini`** — Verify axis limits, velocities, and HAL files are correct
2. **Check `custom_config.yml`** — Verify file locations and VCP options
3. **Review `setup.log`** — Check for any unexpected settings or missing files
4. **Test with LinuxCNC simulator** before connecting to real hardware
5. **Update your desktop launcher** to point to the new config:
   ```ini
   [Desktop Entry]
   Exec=sh -c "linuxcnc $HOME/linuxcnc/configs/monokrom_my_config/monokrom.ini"
   ```

## Troubleshooting

### No .prefs file found

The source config directory must contain a `.prefs` file. If missing, the setup will fail.
This file is generated by PnCconf/StepConf and contains the plasma settings.

### Duplicate option errors

Some qtplasmac configs have duplicate INI keys (e.g., `POSITION_FEEDBACK` appearing twice).
The setup tool handles this by using the last occurrence for single-value keys.

### Template files not found

If the `linuxcnc/configs/templates/plasmac/` directory is missing, the setup will still
run but some files (like `plasma_table.db`) may not be generated. Ensure the templates
directory exists in your MonoKrom installation.

### Output directory already exists

If the output directory already exists, the setup will overwrite files. Back up your
existing config before running the setup.
