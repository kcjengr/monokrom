# G-Code Syntax

This reference documents the G-code syntax and structure used by MonoKorn Plasma. It covers
the G-code commands generated by Quickshapes, the M-codes used for plasma control, and the
special comments and directives recognized by the VCP.

## Supported G-Code Commands

MonoKorn Plasma supports the standard LinuxCNC G-code command set, with the following
plasma-specific conventions:

### Motion Commands

| Command | Description |
|---------|-------------|
| `G0` | Rapid positioning |
| `G1` | Linear interpolation (cutting feed) |
| `G2` | Clockwise arc interpolation |
| `G3` | Counter-clockwise arc interpolation |
| `G4` | Dwell (delay) |
| `G10` | Set coordinate system offset |
| `G28` | Return to home position |
| `G30` | Return to reference position |
| `G54` - `G59` | Coordinate system selection |
| `G90` | Absolute programming (default) |
| `G91` | Incremental programming |
| `G94` | Feed rate per minute (default) |
| `G95` | Feed rate per revolution |

### Plasma-Specific M-Codes

| Command | Description |
|---------|-------------|
| `M3` | Torch on (spindle forward = arc start) |
| `M4` | Torch on (spindle reverse — rarely used) |
| `M5` | Torch off (spindle stop = arc stop) |
| `M7` | Coolant mist on (if equipped) |
| `M8` | Coolant flood on (if equipped) |
| `M9` | Coolant off |

### Plasma-Specific Macros

| Command | Description |
|---------|-------------|
| `M30` | Program end and rewind |
| `M0` | Program stop (operator pause) |
| `M1` | Optional stop (if enabled) |

## Quickshape G-Code Structure

Each Quickshape generates a complete G-code program with the following structure:

```gcode
; MonoKrom Quickshape - <shape name>
; Material: <selected material>
; Gas: <gas type>
; Machine: <machine type>
; Thickness: <thickness>
; Kerf: <kerf value>
; Lead-in: <lead-in length>
; Pierce Height: <pierce height>
; Pierce Delay: <pierce delay>
; Cut Height: <cut height>
; Cut Feed Rate: <cut feed rate>
; Cut Volts: <cut volts>

(Start of shape program)
G90 G94          (Absolute mode, feed per minute)
G0 Z<pierce height>              (Rapid to pierce height)
G1 Z<pierce height> F<probe speed>  (Probe approach at probe speed)
; Ohmic probe or height sense occurs here if enabled
G0 Z<pierce height>              (Rapid to pierce height again)
G4 P<pierce delay>               (Pierce delay)
G1 Z<cut height> F<cut feed rate>  (Lower to cut height)
G4 P<pierce delay>               (Pierce delay at cut height)
M3                               (Torch on)
G1 X<lead-in start> F<cut feed rate>  (Lead-in move)
G1 <cut path> F<cut feed rate>      (Cut path with kerf compensation)
M5                               (Torch off)
G0 Z<safe height>                (Retract to safe height)
M30                              (Program end)
```

## Arc Start Sequence

The arc start sequence is standardized across all cut operations:

```gcode
; Step 1: Rapid to pierce height
G0 Z<pierce height>

; Step 2: Approach to pierce height at probe speed
G1 Z<pierce height> F<probe speed>

; Step 3: Ohmic probe (if enabled)
; The VCP applies ohmic voltage and detects contact with the workpiece.
; If ohmic probe succeeds, the Z position is recorded.
; If ohmic probe fails, the float switch is used as fallback.

; Step 4: Rapid to pierce height (after probe)
G0 Z<pierce height>

; Step 5: Pierce delay
G4 P<pierce delay>

; Step 6: Lower to cut height
G1 Z<cut height> F<cut feed rate>

; Step 7: Pierce delay at cut height
G4 P<pierce delay>

; Step 8: Torch on
M3

; Step 9: Optional puddle jump
; If puddle jump is enabled:
G0 Z<puddle jump height>
G4 P<puddle jump delay>
G1 Z<cut height> F<cut feed rate>

; Step 10: Begin cutting
G1 <cut path> F<cut feed rate>
```

## Hole Cutting

Holes smaller than the hole detection threshold are cut as through-cuts without lead-ins:

```gcode
; Small hole (through-cut, no lead-in)
G0 Z<pierce height>
G1 Z<pierce height> F<probe speed>
G0 Z<pierce height>
G4 P<pierce delay>
G1 Z<cut height> F<cut feed rate>
G4 P<pierce delay>
M3
G1 X<hole center X> Y<hole center Y> F<cut feed rate>  (Position over hole)
G3/X<hole end> I<J offset> F<cut feed rate>  (Circle cut, no lead-in)
M5
G0 Z<safe height>
```

Large holes (above the threshold) use lead-ins:

```gcode
; Large hole (with lead-in)
G0 Z<pierce height>
G1 Z<pierce height> F<probe speed>
G0 Z<pierce height>
G4 P<pierce delay>
G1 Z<cut height> F<cut feed rate>
G4 P<pierce delay>
M3
G1 X<lead-in start> F<cut feed rate>  (Lead-in to hole)
G3/X<hole end> I<J offset> F<cut feed rate>  (Circle cut with lead-in)
G1 X<lead-in end> F<cut feed rate>  (Lead-out)
M5
G0 Z<safe height>
```

## Kerf Compensation

Kerf compensation is applied automatically to all cut paths. The compensation offset is
calculated as:

```
compensation = kerf / 2
```

For external cuts (outer perimeters), the path is offset outward by the compensation amount.
For internal cuts (holes, cutouts), the path is offset inward by the compensation amount.

The kerf value is stored per material in the process database.

## Coordinate Systems

MonoKorn Plasma supports the standard LinuxCNC coordinate systems:

| G-Code | Description |
|--------|-------------|
| `G54` | Work coordinate system 1 (default) |
| `G55` | Work coordinate system 2 |
| `G56` | Work coordinate system 3 |
| `G57` | Work coordinate system 4 |
| `G58` | Work coordinate system 5 |
| `G59` | Work coordinate system 6 |

Coordinate system offsets are set in the INI file or via `G10 L2 P<n> X<offset> Y<offset>`.

### Sheet Alignment

The Sheet Alignment service applies a rotation to the work coordinate system using `G10`:

```gcode
; Set rotation angle for work coordinate system 1
G10 L2 P0 R<angle>
```

Where `<angle>` is the rotation angle in degrees, calculated from two reference points
marked by the operator using the laser pointer.

## Comments

MonoKorn Plasma uses standard LinuxCNC comment syntax:

| Syntax | Description |
|--------|-------------|
| `; comment` | Semicolon comment (ignored by LinuxCNC) |
| `(comment)` | Parentheses comment (ignored by LinuxCNC) |

Comments in generated G-code include:
- Material information (material name, gas, machine, thickness)
- Cut parameters (kerf, lead-in, pierce height, cut height, feed rate)
- Shape name and generation timestamp

## Program Control

### Run From Line

MonoKorn Plasma supports resuming a program from a specific line:

1. Open the G-code editor.
2. Place the cursor on the desired line.
3. Press `Ctrl+R` or click **Run From Line**.
4. The program resumes from the selected line.

**Important:** When resuming from a line, ensure the torch is at the correct position
and height. Use Cut Recovery to reposition if necessary.

### Block Delete

Block delete skips lines preceded by a `/` character. This can be used to skip optional
operations (e.g., probe sequences) for testing:

```gcode
/ G0 Z<pierce height>    (Skipped if block delete is enabled)
G1 Z<pierce height> F<probe speed>  (Not skipped)
```

Block delete is controlled by the LinuxCNC HALUI pin `halui.program.block-delete`.

### Optional Stop

Optional stop (`M1`) pauses the program if optional stop is enabled. This can be used
to mark specific points in a program for operator inspection:

```gcode
M1    (Pause if optional stop is enabled)
```

Optional stop is controlled by the LinuxCNC HALUI pin `halui.program.optional-stop`.

## Special Directives

### Material Selection Directive

Some G-code files may include a directive to select a material from the process database:

```gcode
; MONOKROM_MATERIAL: Mild Steel 6mm
```

This directive is ignored by LinuxCNC but can be parsed by MonoKorn Plasma to automatically
select the matching material from the process database when the file is loaded.

### Custom Parameters

Custom parameters can be passed to the VCP via G-code comments:

```gcode
; MONOKROM_CUSTOM_PARAM: value
```

These are currently not processed by the VCP but are reserved for future use.

## G-Code Validation

MonoKorn Plasma includes basic G-code validation when loading a program:

| Check | Description |
|-------|-------------|
| **Syntax** | Validates G-code syntax (valid commands, proper format) |
| **Limits** | Checks that positions are within machine limits |
| **Spindle** | Warns if M3/M4/M5 commands are missing or malformed |
| **Z axis** | Warns if Z moves are missing before X/Y moves |
| **Program end** | Warns if program does not end with M30 |

Validation errors are displayed in the status bar when loading a program.

## Example: Complete Quickshape Program

Here is a complete example of a Quickshape-generated program for a 100mm circle on
3mm mild steel with air plasma:

```gcode
; MonoKrom Quickshape - Circle
; Material: Mild Steel
; Gas: Air
; Machine: A120
; Thickness: 3mm
; Kerf: 1.2mm
; Lead-in: 5mm
; Pierce Height: 6.0mm
; Pierce Delay: 1.0s
; Cut Height: 3.5mm
; Cut Feed Rate: 1200mm/min
; Cut Volts: 85V

G90 G94
G0 Z6.0
G1 Z6.0 F25
G0 Z6.0
G4 P1.0
G1 Z3.5 F1200
G4 P1.0
M3
G1 X-5 F1200
G1 X0 Y0 F1200
G3 X0 I50 F1200
G1 X-5 F1200
M5
G0 Z50
M30
```
